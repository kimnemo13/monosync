# monoSync

Premiere Pro 패널 — 내가 준 자막 텍스트를 작품 속 대사에 맞춰 타임라인에 배치해요.

1. 자막 텍스트를 붙여 넣거나 txt로 불러오기
2. 타임라인에서 대사 클립 선택 → 가져오기
3. 대사 맞추기 (whisper.cpp로 이 맥에서 단어 단위 받아쓰기 → 글자 단위로 자막과 정렬)
4. 캡션 트랙으로 넣기 → 트랙 스타일로 내 형식 적용

- **대사 그대로** 모드: 자막이 대사를 받아 적은 것일 때. 자막 안 단 대사·잡음은 건너뛰고, 못 찾은 줄은 앞뒤 사이에 추정 배치(주황).
- **번역 자막** 모드: 대사와 자막 언어가 다를 때. 말소리 구간의 순서·길이로 대략 배치.
- 인식 결과는 캐시돼서, 자막 텍스트만 고쳐 다시 맞추면 바로 끝나요.

설치는 `설치안내.txt` 참고. 사용 통계·데이터 전송 없음.
