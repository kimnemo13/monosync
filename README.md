# monoSync

Premiere Pro 패널 — 자막 텍스트를 내 음성(내레이션)이나 작품 대사에 맞춰 타임라인에 배치해요.

1. 자막 텍스트 붙여 넣기 (한 줄 = 자막 클립 하나)
2. 자막 넣을 V트랙, 음성 A트랙, 범위 고르기
3. 자막 모양 템플릿(.mogrt) 고르기 — 쓰던 자막 클립을 모션 그래픽 템플릿으로 내보낸 것
4. **싱크** → A트랙 음성을 이 맥에서 받아쓰고(whisper.cpp) 글자 단위로 맞춰, V트랙에 그래픽 클립으로 넣음

- 음성에서 못 찾은 줄은 앞뒤 사이에 추정 배치(주황). 인식 결과는 저장돼서 텍스트만 고쳐 다시 싱크하면 바로 끝나요.
- 캡션 트랙으로 넣기, SRT 저장, 번역 자막 모드(세부 설정)도 있어요.

설치는 `설치안내.txt` 참고. 사용 통계·데이터 전송 없음.
